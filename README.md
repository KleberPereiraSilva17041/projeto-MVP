# projeto-MVP# Gestão Fácil
### Sistema de Gestão para Pequenos Negócios

## Sobre o projeto
O Gestão Fácil é um sistema web desenvolvido como parte da Experiência Prática III da disciplina de Projeto de Software.

O objetivo é oferecer uma solução simples e intuitiva para auxiliar pequenos estabelecimentos comerciais no gerenciamento de clientes, produtos, estoque e vendas.

## Objetivos
- Facilitar o gerenciamento de clientes.
- Controlar produtos e estoque.
- Registrar e consultar vendas.
- Oferecer uma interface intuitiva.
- Aplicar boas práticas de engenharia de software.

## Tecnologias
- Python
- Flask
- HTML, CSS e JavaScript
- Bootstrap 5
- SQLAlchemy
- PostgreSQL
- Git e GitHub
- Pytest
- GitHub Actions

## Funcionalidades
- Cadastro de clientes.
- Cadastro de produtos.
- Controle de estoque.
- Registro de vendas.
- Autenticação de usuários.
