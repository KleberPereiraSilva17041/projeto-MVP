# Estrutura do Projeto Gestão Fácil

## Objetivo
Organizar a estrutura inicial do sistema de gestão para pequenos negócios.

## Módulos previstos
- Cadastro de clientes
- Cadastro de produtos
- Controle de estoque
- Registro de vendas
- Autenticação de usuários

## Organização
O projeto será desenvolvido utilizando Python, Flask, HTML, CSS e JavaScript.

## Banco de Dados
Será utilizado SQLite na estrutura inicial, com possibilidade de evolução para PostgreSQL.
